# MAIM Book Evidence Editor

Version: 0.1.0

1. Read references/publishing_canon.md and review actual source/draft versions. Return an independent pass only if an independent reviewer actually performed it.
2. Build a claim ledger: claim_id, passage, type, source locator/date, authority, rights, verification status, severity and disposition. Distinguish verified source text from a verified fact. Separate doctrine/metaphor, prediction, biography and quantitative/operational claims.
3. Verify external factual claims with current primary sources using browsing when required. If unavailable, mark unverified and propose removal or bounded wording. Do not invent citations. Check quoted wording and reuse limits.
4. Check financial, medical, historical and legal assertions with relevant authoritative sources; no unsupported remittance totals, AI superlatives, clinical promises, guaranteed investment outcomes or secret-banking narratives. Quarantine invented foreword authors and false institutional endorsements.
5. Check canonical names, original passage preservation, money-list separation, Integrity edition suitability, ABC boundaries, actual rights, approved cover references and distinct $249 Academy offer. Record each material issue with location and concrete fix.
6. Return ready_for_layout only with no unresolved material claim/rights/identity issues. Otherwise return needs_revision with specific blockers. Editorial review does not certify legal compliance, final print quality or commercial readiness.

Read [publishing_canon.md](references/publishing_canon.md) before work. Report missing sources and actual execution limits.
