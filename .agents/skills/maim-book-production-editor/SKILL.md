# MAIM Book Production Editor

Version: 0.1.0

1. Read references/publishing_canon.md. Require a named manuscript version, collection/edition identity, evidence review and rights ledger before calling an artifact a release candidate. Continue permitted reversible preparation without repeated approvals.
2. Pair with installed document/PDF skills for exports and brand/design skills for exact assets. For Integrity preserve six cover alternatives, both front/back, actual portrait and MD marks. Do not regenerate missing approved identity assets.
3. Build metadata: collection, title, subtitle, author, edition/age, language, source version, formats, cover IDs, accessibility checks, rights, approval status and checksums. Leave ISBN/barcode identifiers unassigned unless actually provided. Never invent certification or endorsement.
4. Render and inspect PDF pages, embedded fonts, headings, contents links, contrast and text extraction. For EPUB verify navigation, reflow, image descriptions and reader behavior with available validators; record unavailable checks. Do not call an untested EPUB accessible.
5. Distinguish review PDF, ebook export and print-ready edition. Require actual printer trim, binding, paper, bleed and final page count before spine calculations. No automatic page shrinking to hit length.
6. Return editable source, exports, proof findings and release manifest. App features, bundle pricing, entitlements and Academy access remain separate decisions. Prepare a concrete publication handoff; do not deploy, activate checkout, send announcements or publish externally without actual authorization.

Read [publishing_canon.md](references/publishing_canon.md) before work. Report missing sources and actual execution limits.
