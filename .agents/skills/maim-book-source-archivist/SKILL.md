# MAIM Book Source Archivist

Version: 0.1.0

1. Read references/publishing_canon.md. Recover before replacing; inspect actual content rather than titles or summaries alone.
2. Search the authorized repository tree, relevant history and supplied files; consult named Drive/Notebook leads through available connectors. Record inaccessible leads explicitly. Do not broaden to unrelated private files.
3. Assign source IDs; record filename, repository/ref or original locator, checksum where available, physical PDF pages, rights status and authority. Separate founder writing, AI drafts, third-party references, placeholders and proposals.
4. Preserve existing passages in a recovery companion with page/line references. Do not republish private source or third-party full text into public Git; retain authorized locators and minimal necessary findings instead.
5. Build a reconciliation table: retain verbatim / edit with provenance / adapt with permission / quarantine / missing. A phrase such as “chapters already written” is not chapter text. A visible filename is not inspected content.
6. Return source inventory, recovered text or safe locators, evidence gaps and passage-to-outline mapping. Claim source exhaustion only for surfaces actually inspected. Never fabricate missing book sections, 20 principles, eight doctrines, or founder history.

Read [publishing_canon.md](references/publishing_canon.md) before work. Report missing sources and actual execution limits.
